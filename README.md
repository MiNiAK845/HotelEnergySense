# HotelEnergySense

HotelEnergySense is a Streamlit-based data science product prototype for energy efficiency optimization using hotel booking demand prediction.

## Objective

The system predicts hotel occupancy demand using hotel booking data and predicts heating/cooling energy loads using an energy efficiency dataset. The outputs are integrated using occupancy probability to estimate adjusted energy consumption.

## Main Features

- Hotel booking demand prediction
- Heating load prediction
- Cooling load prediction
- Occupancy-adjusted energy estimation
- Analytics dashboard
- Model evaluation
- Project Gantt chart
